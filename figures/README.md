# Figure collection

This directory contains the earlier manuscript figure set and retained visual outputs. The folders preserve their supplied names so captions, validation scripts, and manuscript references continue to resolve.

The 104-event extension figures are kept with their frozen analysis under [`../reproducibility/full-catalog-generalization/results/`](../reproducibility/full-catalog-generalization/results/). Keeping those files inside the capsule preserves its checksums and makes the corresponding tables, manifests, and renderers discoverable together.
