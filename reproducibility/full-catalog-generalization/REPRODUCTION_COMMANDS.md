# Reproduction commands

Run these commands from the extension directory. Replace `PATH_TO_HDF5_FILES`
with the directory containing the 104 official event files. The official raw
HDF5 files are referenced by filename and checksum but are not duplicated in
this package.

## 1. Verify the 104 inputs

```powershell
python analysis/build_full_catalog_inventory.py `
  --ranking design/frozen_inputs/catalog_xphm_xpnr_event_ranking.csv `
  --development-freeze design/frozen_inputs/development_set_freeze.json `
  --confirmatory-sample design/frozen_inputs/confirmatory_final_strict_18_event_sample.csv `
  --replication-sample design/frozen_inputs/replication_final_strict_9_event_sample.csv `
  --official-md5 design/official_zenodo_md5sums.txt `
  --input-dir PATH_TO_HDF5_FILES `
  --output-dir reproduced_results/inventory
```

Require `complete_and_verified: true` and exactly 104 verified files in the
inventory summary before continuing.

## 2. Run the outcome-blind metadata audit

```powershell
python analysis/GWTC5_full_catalog_metadata_audit.py `
  --inventory reproduced_results/inventory/full_catalog_input_inventory.csv `
  --output-dir reproduced_results/metadata_audit
```

The frozen reference run classified 93 pairs as strict matched settings, 11 as
non-Tier-A metadata differences, and all 104 as outcome-usable for the H3
census.

## 3. Reproduce the independent H3 census

```powershell
python analysis/GWTC5_full_catalog_generalization_analysis.py `
  --inventory reproduced_results/inventory/full_catalog_input_inventory.csv `
  --inventory-summary reproduced_results/inventory/full_catalog_inventory_summary.json `
  --metadata-summary reproduced_results/metadata_audit/full_catalog_metadata_event_summary.csv `
  --confirmatory-reference reference_results/confirmatory_parameter_metrics.csv `
  --replication-reference reference_results/replication_parameter_metrics.csv `
  --output-dir reproduced_results/h3_census
```

## 4. Reproduce the four-parameter generalization analysis

```powershell
python analysis/full_catalog_generalization_analysis.py `
  --inventory reproduced_results/inventory/full_catalog_input_inventory.csv `
  --ranking design/frozen_inputs/catalog_xphm_xpnr_event_ranking.csv `
  --metadata-summary reproduced_results/metadata_audit/full_catalog_metadata_event_summary.csv `
  --metadata-manifest reproduced_results/metadata_audit/full_catalog_metadata_audit_manifest.json `
  --metric-core-module analysis/frozen_metric_core.py `
  --output-dir reproduced_results/generalization_full
```

This is the longest statistical stage because it performs 100,000
permutations, 100,000 event bootstraps, repeated split references, and
matched-size sensitivity calculations.

## 5. Reproduce the exploratory mechanism analysis

```powershell
python analysis/full_catalog_mechanism_generalization.py `
  --inventory reproduced_results/inventory/full_catalog_input_inventory.csv `
  --metadata-summary reproduced_results/metadata_audit/full_catalog_metadata_event_summary.csv `
  --metadata-manifest reproduced_results/metadata_audit/full_catalog_metadata_audit_manifest.json `
  --metric-core-module analysis/frozen_metric_core.py `
  --output-dir reproduced_results/mechanism_full
```

## 6. Regenerate the two principal figures

```powershell
python figures/make_full_catalog_figures.py `
  --event-endpoints reproduced_results/generalization_full/full_catalog_event_endpoints.csv `
  --generalization-tests reproduced_results/generalization_full/full_catalog_generalization_tests.csv `
  --mechanism-events reproduced_results/mechanism_full/full_catalog_mechanism_event_metrics.csv `
  --mechanism-summary reproduced_results/mechanism_full/full_catalog_mechanism_summary.json `
  --output-dir reproduced_results/figures
```

The separate sorted 104-event H3 figure is generated by
`analysis/make_full_catalog_h3_figure.js`; it requires Node.js with `sharp`.

## 7. Regression checks

```powershell
python tests/test_dependency_light_pipeline.py

python tests/verify_frozen_metric_core.py `
  --metric-core-module analysis/frozen_metric_core.py `
  --inventory reproduced_results/inventory/full_catalog_input_inventory.csv `
  --reference-metrics reference_results/confirmatory_parameter_metrics.csv

python analysis/verify_full_catalog_outputs.py
python tests/test_figure_render.py
```

The archived reference run passed all checks, reproduced all 1,530 frozen
confirmatory metric values, and produced exactly matching H3 deltas through
the independent and comprehensive analysis paths.
